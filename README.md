# ElectroDoc-AI

AI-powered assistant for finding, verifying and simplifying electrical component datasheets.

## 🚀 Live Demo

👉 [Try ElectroDoc](https://hqmlhhhjddscmcgjductqo.streamlit.app/)

## 🛠️ Technologies

- Python
- Streamlit
- Google Gemini
- Tavily
- AI / LLM

## 💡 Problem

Finding the correct datasheet for an electronic component can take time.

## 💡 Solution

ElectroDoc helps users find, verify and understand electrical component datasheets using AI.
