# ElectroDoc-AI

### Find. Verify. Understand.

AI-powered assistant for finding, verifying and simplifying electrical and electronic component datasheets.

## 🚀 Live Demo

👉 [Try ElectroDoc](https://hqmlhhhjddscmcgjductqo.streamlit.app/)

## 💡 Problem

Finding the correct datasheet for an electrical or electronic component can be time-consuming, especially when the exact manufacturer and model number are unknown.

## 💡 Solution

ElectroDoc helps users find relevant component datasheets by using AI and web search. Users can provide component details such as manufacturer, model number and equipment type to locate technical documentation quickly.

## 🔮 Planned Improvement

### 📷 Image-Based Component Recognition

The next version of ElectroDoc will allow users to upload an image of an electrical or electronic component.

The AI will analyze the image to identify:

- Component type
- Manufacturer
- Model/part number
- Visible markings

The extracted information will then be used to search for the relevant datasheet.
